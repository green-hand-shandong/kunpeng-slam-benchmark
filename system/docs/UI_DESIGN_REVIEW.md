# UI 设计评审：布局 · 功能 · 交互（2026-11-02）

> 维度：**布局安排**（信息架构/视觉层次/空间利用）、**功能**（覆盖度/正确性）、**交互逻辑**（流程顺畅度/反馈/防错）。每页评分 1-5。本轮评审后实施 8 项优化（见文末实施记录）。

## 0. 全局

| 项 | 评价 | 分 | 问题与建议 |
|---|---|---|---|
| 信息架构 | 九页平铺导航，查看/操作/系统类混排，无分组 | 3 | 【已改】导航分四组：数据 / 运行与分析 / 系统 |
| 视觉一致性 | 蓝白主题统一；图表画布曾残留深色（已修）；无 favicon | 4 | 【已改】加 favicon；统一 ok |
| 反馈机制 | 按钮加载态、错误卡片、进度百分比已有；自动刷新无指示 | 4 | 【已改】总览刷新指示器 |
| 防错 | confirm/防御/竞态令牌已覆盖关键路径 | 4 | 良好 |
| 响应式 | 190px 侧栏固定，窄屏(<900px)挤压内容 | 2 | 【已改】<900px 侧栏转顶部横排 |
| 可达性 | 输入有 focus 环；无键盘快捷键、无 aria | 3 | P2（对内网工控场景影响小） |

## 1. 登录页 —— 4.5/5
- 布局：独立全屏 + 居中卡片，无侧栏干扰 ✅；软件全称 + 版本副标题 ✅
- 交互：回车提交 ✅、错误提示内联 ✅、初始口令提醒 ✅
- 建议：CapsLock 检测（P3）；登录后跳转回原目标页（当前固定 overview，P2）

## 2. 系统总览 —— 4/5
- 布局：指标卡 + 版本条 + 模块表，层次清晰
- 功能：真实 /proc 数据 ✅、5s 自动刷新 ✅
- 问题：①磁盘 81% 无预警色；②自动刷新用户无感知；③FAST-LIO commit 原始输出略糙
- 建议：【已改】①磁盘 >85% 黄 / >90% 红；②标题旁"● 5s 自动刷新"指示；③commit 截短为 hash

## 3. 数据集管理 —— 4/5
- 布局：注册表在上、导入表单在下，合理
- 功能：9 项体检校验是亮点；帧数/时长/大小齐全
- 交互：导入表单值切页保留 ✅；校验按钮 loading+恢复 ✅
- 建议：路径即时校验（失焦检查存在性，P2）；"校验"按钮宜逐行而不是放行内（当前可用，保留）

## 4. 建图任务 —— 3.5/5
- 功能：历史/失败原因/条件链接齐
- 问题：①"正在运行"区与工作台功能重叠，两处入口易混淆；②无重试按钮
- 建议：【已改】失败行加"重试"按钮（一键以原配置重启）；合并入口列为 V1.1

## 5. 三维工作台 —— 3.5/5（演示核心，投入最大）
- 功能：点云/轨迹/相机/HUD/状态保留 ✅
- 问题：①**无视角预设**（演示时手动拖到俯视很费劲）；②**无点大小调节**（密集点糊成一片）；③HUD 与工具条信息分散
- 建议：【已改】工具条加"俯视/侧视/自由"预设按钮 + 点大小滑块；HUD 聚合保持
- 遗留：逐帧回放/跟随视角（P1，Potree 迁移一并做）

## 6. 算法配置 —— 4/5
- 布局：参数表（值/范围/说明）+ 生效文件对照，清晰
- 交互：number 输入带范围校验 ✅；保存/恢复默认 ✅
- 建议：修改后未保存就切页应提示（P2）；预设方案模板（保守/均衡/激进）P2

## 7. 轨迹质量评估 —— 4/5
- 功能：ATE/RPE/曲线(带坐标轴)/双轨迹对比齐
- 问题：①**缺直观质量等级**——用户要看"到底好不好"，4.83m 没有参照；②对比图例文字小
- 建议：【已改】ATE 卡片加质量徽章（按 ATE/轨迹长度百分比：≤1% 优 / ≤3% 良 / ≤5% 合格 / >5% 差）

## 8. 实验管理 —— 3.5/5
- 功能：对比/导出（大小+确认+降采样）齐
- 问题：①实验增多后无筛选；②对比只能选两次
- 建议：【已改】表加数据集/状态筛选下拉；多选对比列 V1.1

## 9. 运行日志 —— 4/5
- 功能：检索/下载/自动刷新开关/状态保留齐
- 问题：①**终端 ANSI 控制符噪声**（roslaunch 彩色码污染阅读）；②无级别过滤（900 行 set -x 里找 error 很痛苦）
- 建议：【已改】后端输出剥离 ANSI 码；前端加"仅错误"快捷过滤

## 10. 闭环分析 —— 3.5/5
- 功能：双源检测/参数可调/候选表真实
- 交互：参数语义清楚（半径/最小间隔）
- 建议：候选点与三维工作台联动高亮（P2，需跨页传参）；位姿图优化 V2.x

## 11. 用户与权限 —— 4/5
- 功能：CRUD/改密/审计/角色控制全
- 交互：危险操作有确认；自己的角色/删除被禁用 ✅
- 建议：首次登录强制改密（P2）；密码强度提示（P3）

## 12. 关于软件 —— 4.5/5
软著申报信息齐备；著作权人待定项已标注。
