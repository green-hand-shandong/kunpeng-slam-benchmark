**P1（影响演示/交付）**

2. 3D 大地图加载：64.7M 点抽样到 150 万，首次抽样 ~10s；V1.1 Potree LOD 后可免抽样流式加载。
3. 逐帧回放/相机跟随未实现（业务演示价值最高的缺失项）。

6. ATE 参考=GPS/INS，需在报告中显著标注；官方真值序列（Odometry 00~10）接入后口径升级。
