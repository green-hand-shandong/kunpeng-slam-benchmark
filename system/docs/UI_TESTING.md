## 二、本轮修复的缺陷（迭代 1）

1. `doValidate` 无按钮上下文时崩溃（`btn.disabled` 对 null 赋值）→ 加 null 防御 + try/finally，并补全异常路径的错误卡片
2. `/api/jobs/{id}/log/download` 后端路由缺失（前端链接 404）
3. `watchJob`/`loadMap` 未暴露到 window（外部集成与测试不可达）
4. 登录页卡片样式与 login-mode 类联调确认（严格 DOM 下验证 body class 真实切换）

## 三、遗留优化（V1.1，按价值排序）

1. **逐帧回放 + 相机跟随**（工作台核心缺失，Potree 迁移一并做）
2. **图表交互**（tooltip/缩放——手绘 canvas 的天花板，ECharts 化解决）
3. 表格排序/分页（实验数 >50 后）
4. 闭环页候选点在三维工作台联动高亮
5. 批量实验导出（zip）
